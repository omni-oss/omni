# R08.1: Cache storage audit (`hybrid.rs`)

Generic storage (moved to `omni_cache::storage`, R08.2/R08.3):
- staging dir naming and atomic publish with sentinel and retry (`publish_staged_dir`)
- stale staging reclaim (`reclaim_stale_staging_dirs`)
- atomic single-file write (`write_atomic`, used by the last-used db)
- internal-entry (`.`-prefixed) detection, advisory lock files (`storage::lock`)

Task semantics (stay in `hybrid.rs`): entry layout (`<project>/output/<digest>`), `cache.meta.bin`
msgpack metadata, exit-code upgrade rules, hard-link/copy of outputs, remote sync, prune filters,
last-used db schema.

No integrity checksum exists on disk today; completeness is the metadata sentinel written last.
Adding an envelope would change the format, so it is out of scope.

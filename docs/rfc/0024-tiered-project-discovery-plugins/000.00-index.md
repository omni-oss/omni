## Overview

Opt-in native and Wasm plugins infer ordinary omni projects from ecosystem
manifests while the host owns discovery, composition, scheduling, permissions and
caching. Explicit configuration remains authoritative. The initial native
adapters cover JavaScript package managers and Cargo. Wasmtime is the selected
Wasm engine and the Component Model (WIT) the external ABI, per prototype evidence.

For the current code-grounded assessment, implementation gates and the single
active decision checklist, see [Readiness and open decisions](018.00-readiness-and-open-decisions.md).

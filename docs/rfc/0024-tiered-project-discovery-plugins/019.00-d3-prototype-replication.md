## 19. Appendix: D3 prototype design and replication

This appendix records what was built and measured to resolve D3 ([§10.1](010.00-implementation-and-rollout.md#101-d3-prototype-evidence)), with
enough source to recreate it. The prototype crates were **not** committed: they were
throwaway experiments. Recreate them in a scratch workspace (the original used omni's
crate generator, `omni generator run -n crate`, inside the omni workspace) or any
Cargo workspace. Results are single-machine, Linux x86_64, release builds, medians.

### 19.1 Design

- **Question:** core-Wasm SDK message ABI versus Component Model/WIT on Wasmtime,
  plus whether synchronous hooks under async Wasmtime bound blocked host calls.
- **Shared workload** (`logic.rs`): `infer(roots)` scans a minimal `name = "..."` /
  `dep = "..."` manifest per root and returns a project with fixed tasks
  `build`, `check`, `test` and its dependencies. `workload(n, padding)` generates
  `n` roots with `padding` filler lines each. Identical logic in every guest.
- **Core guest:** exports `alloc`, `dealloc`, `infer(ptr, len) -> (ptr << 32) | len`
  with JSON in linear memory (a stand-in for an SDK-managed message ABI), plus
  `spin`, `grow(pages)` and `trap` enforcement probes.
- **Component guest:** the same logic behind a typed WIT interface; also exports
  `spin`, `grow`, `trap` and `call-block`, and imports a `host.block(ms)` service.
- **Async guest:** a WIT `async func` export calling an `async func` import.
- **Host harness:** one shared `Engine`, compiled once; a fresh `Store` per call
  with a memory limiter; optional fuel and epoch interruption; no linker imports
  beyond the explicit `host` interface. Measures size, cold compile, precompiled
  size/deserialize, instantiate, `infer` latency at several payload sizes with and
  without fuel+epoch, and enforcement (fuel, epoch, memory cap, trap, host health).
- **Async harness:** compares (1) sync import/sync call, (2) async host import with
  the call future dropped on a Tokio timeout, (3) Component Model `async func`;
  plus eight concurrent 200 ms calls on a current-thread runtime and per-invocation
  overhead.

The async guest's `wit/world.wit` was a symlink to the component guest's file (the
world file below defines all worlds). In `wit-bindgen` 0.63 the `async: true` option
no longer exists: WIT `async func` gets async bindings by default. Wasmtime's
`async func` bindings use `HostWithStore<T>` and `Store::run_concurrent` with an
`Accessor`.

### 19.4 Observed limits of this prototype

Known issues in the published source (found in review, not yet re-run because the
recording environment was out of disk): (1) `d3.rs` instantiates the `plugin` world
with an empty `Linker`, but that world imports `host`; add a `Host` implementation
plus `Plugin::add_to_linker`, or split an import-free world for the inference and
enforcement runs, and re-verify the import set. (2) The "core+json" timing serializes
the input before the timed call, while the component timing includes canonical ABI
encoding; treat the core-versus-component gap as excluding JSON serialization, or move
`serde_json::to_vec` inside the timed section. (3) `d3_async.rs` awaits a Tokio timer
for 0 ms while `d3_pool.rs` returns immediately, so rerun both with the same host
operation before attributing the difference to linker reuse and `InstancePre`.

See [§10.1](010.00-implementation-and-rollout.md#101-d3-prototype-evidence) for results and unmeasured items. Notable pitfalls found:
`wasm32-wasip2` std builds import WASI; `wasmtime::Error` is not `std::error::Error`
(use `wasmtime::Result`); panic messages are lost unless a host hook forwards them;
and the initial 1.3 ms async overhead came from per-call setup: with a linker and
`InstancePre` built once it falls to roughly 30 µs (default allocator) or 10 µs
(pooling allocator). The pooling allocator needs Wasmtime's `pooling-allocator`
feature.

```rust
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Root {
    pub path: String,
    pub manifest: String,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Project {
    pub name: String,
    pub root: String,
    pub tasks: Vec<String>,
    pub deps: Vec<String>,
}

fn quoted(line: &str, key: &str) -> Option<String> {
    let rest = line.strip_prefix(key)?.trim_start().strip_prefix('=')?;
    Some(rest.trim().trim_matches('"').to_string())
}

pub fn infer_one(root: &Root) -> Option<Project> {
    let mut name = None;
    let mut deps = Vec::new();
    for line in root.manifest.lines() {
        if let Some(n) = quoted(line, "name") {
            name = Some(n);
        } else if let Some(d) = quoted(line, "dep") {
            deps.push(d);
        }
    }
    Some(Project {
        name: name?,
        root: root.path.clone(),
        tasks: ["build", "check", "test"].map(String::from).to_vec(),
        deps,
    })
}

pub fn infer(roots: &[Root]) -> Vec<Project> {
    roots.iter().filter_map(infer_one).collect()
}

pub fn workload(n: usize, padding: usize) -> Vec<Root> {
    (0..n)
        .map(|i| Root {
            path: format!("crates/pkg{i}"),
            manifest: format!(
                "name = \"pkg{i}\"\ndep = \"pkg{}\"\n{}",
                (i + 1) % n.max(1),
                "# pad\n".repeat(padding)
            ),
        })
        .collect()
}
```

```rust
//! Core-Wasm message ABI guest: length-prefixed JSON in linear memory.
#![allow(dead_code, clippy::missing_safety_doc)]
#[path = "../../omni_wasm_proto/src/logic.rs"]
mod logic;

#[unsafe(no_mangle)]
pub extern "C" fn alloc(len: u32) -> u32 {
    let mut v = Vec::<u8>::with_capacity(len as usize);
    let p = v.as_mut_ptr();
    std::mem::forget(v);
    p as u32
}

#[unsafe(no_mangle)]
pub unsafe extern "C" fn dealloc(ptr: u32, len: u32) {
    drop(unsafe { Vec::from_raw_parts(ptr as *mut u8, 0, len as usize) });
}

/// Returns `(ptr << 32) | len` of the JSON output buffer (host frees via `dealloc`).
#[unsafe(no_mangle)]
pub unsafe extern "C" fn infer(ptr: u32, len: u32) -> u64 {
    let input = unsafe { std::slice::from_raw_parts(ptr as *const u8, len as usize) };
    let roots: Vec<logic::Root> = serde_json::from_slice(input).unwrap();
    let mut out = serde_json::to_vec(&logic::infer(&roots)).unwrap();
    out.shrink_to_fit();
    let (p, l) = (out.as_mut_ptr() as u64, out.len() as u64);
    std::mem::forget(out);
    (p << 32) | l
}

#[unsafe(no_mangle)]
pub extern "C" fn spin() {
    let mut x = 0u64;
    loop {
        x = std::hint::black_box(x.wrapping_add(1));
    }
}

#[unsafe(no_mangle)]
pub extern "C" fn grow(pages: u32) -> u32 {
    let v = vec![1u8; pages as usize * 65536];
    std::hint::black_box(&v);
    v.len() as u32
}

#[unsafe(no_mangle)]
pub extern "C" fn trap() {
    panic!("guest trap");
}
```

```rust
#![allow(dead_code, clippy::missing_safety_doc)]
#[path = "../../omni_wasm_proto/src/logic.rs"]
mod logic;

wit_bindgen::generate!({ world: "plugin", path: "wit" });

use exports::omni::proto::discovery as d;

struct Plugin;

impl d::Guest for Plugin {
    fn infer(roots: Vec<d::Root>) -> Vec<d::Project> {
        let roots: Vec<logic::Root> = roots
            .into_iter()
            .map(|r| logic::Root { path: r.path, manifest: r.manifest })
            .collect();
        logic::infer(&roots)
            .into_iter()
            .map(|p| d::Project { name: p.name, root: p.root, tasks: p.tasks, deps: p.deps })
            .collect()
    }
    fn spin() {
        let mut x = 0u64;
        loop {
            x = std::hint::black_box(x.wrapping_add(1));
        }
    }
    fn grow(pages: u32) -> u32 {
        let v = vec![1u8; pages as usize * 65536];
        std::hint::black_box(&v);
        v.len() as u32
    }
    fn call_block(ms: u32) -> u32 {
        omni::proto::host::block(ms)
    }
    fn trap() {
        panic!("guest trap");
    }
}

export!(Plugin);
```

#### `crates/omni_wasm_proto/examples/d3.rs`

```rust
//! D3 prototype harness. Usage:
//! `cargo run --release -p omni_wasm_proto --example d3 -- <core.wasm> <component.wasm>`
use std::time::{Duration, Instant};

use wasmtime::Result;
use omni_wasm_proto::logic::{self, Project, Root};
use wasmtime::component::{Component, Linker as CLinker};
use wasmtime::{Config, Engine, Linker, Module, Store, StoreLimits, StoreLimitsBuilder};

wasmtime::component::bindgen!({
    world: "plugin",
    path: "../omni_wasm_proto_guest_component/wit",
});

use exports::omni::proto::discovery as d;

struct Host {
    limits: StoreLimits,
}

fn engine(fuel: bool, epoch: bool) -> Result<Engine> {
    let mut c = Config::new();
    c.consume_fuel(fuel);
    c.epoch_interruption(epoch);
    Engine::new(&c)
}

fn store(e: &Engine, mem: usize, fuel: bool, epoch: bool) -> Store<Host> {
    let mut s = Store::new(
        e,
        Host { limits: StoreLimitsBuilder::new().memory_size(mem).trap_on_grow_failure(true).build() },
    );
    s.limiter(|h| &mut h.limits);
    if fuel {
        s.set_fuel(u64::MAX / 2).unwrap();
    }
    if epoch {
        s.set_epoch_deadline(u64::MAX / 2);
    }
    s
}

fn median(mut v: Vec<Duration>) -> Duration {
    v.sort();
    v[v.len() / 2]
}

fn time<T>(reps: usize, mut f: impl FnMut() -> T) -> Duration {
    median((0..reps).map(|_| { let t = Instant::now(); std::hint::black_box(f()); t.elapsed() }).collect())
}

fn to_wit(r: &[Root]) -> Vec<d::Root> {
    r.iter().map(|r| d::Root { path: r.path.clone(), manifest: r.manifest.clone() }).collect()
}


fn core_call(e: &Engine, m: &Module, input: &[u8], fuel: bool, epoch: bool) -> Result<usize> {
    let mut s = store(e, 1 << 30, fuel, epoch);
    let inst = Linker::<Host>::new(e).instantiate(&mut s, m)?;
    let mem = inst.get_memory(&mut s, "memory").unwrap();
    let alloc = inst.get_typed_func::<u32, u32>(&mut s, "alloc")?;
    let infer = inst.get_typed_func::<(u32, u32), u64>(&mut s, "infer")?;
    let p = alloc.call(&mut s, input.len() as u32)?;
    mem.write(&mut s, p as usize, input)?;
    let r = infer.call(&mut s, (p, input.len() as u32))?;
    let (op, ol) = ((r >> 32) as usize, (r & 0xffff_ffff) as usize);
    let out = mem.data(&s)[op..op + ol].to_vec();
    let projects: Vec<Project> = serde_json::from_slice(&out)?;
    Ok(projects.len())
}

fn comp_call(e: &Engine, c: &Component, roots: &[d::Root], fuel: bool, epoch: bool) -> Result<usize> {
    let mut s = store(e, 1 << 30, fuel, epoch);
    let p = Plugin::instantiate(&mut s, c, &CLinker::<Host>::new(e))?;
    Ok(p.omni_proto_discovery().call_infer(&mut s, roots)?.len())
}

fn main() -> Result<()> {
    let a: Vec<String> = std::env::args().collect();
    let (core_bytes, comp_bytes) = (std::fs::read(&a[1])?, std::fs::read(&a[2])?);
    println!("## sizes\ncore .wasm: {} B\ncomponent .wasm: {} B", core_bytes.len(), comp_bytes.len());

    let e = engine(false, false)?;
    println!("\n## compile (cold, Cranelift)");
    let t = Instant::now(); let cm = Module::new(&e, &core_bytes)?; println!("core: {:?}", t.elapsed());
    let t = Instant::now(); let cc = Component::new(&e, &comp_bytes)?; println!("component: {:?}", t.elapsed());
    let (sm, sc) = (cm.serialize()?, cc.serialize()?);
    println!("precompiled artifact: core {} B, component {} B", sm.len(), sc.len());
    println!("deserialize: core {:?}, component {:?}",
        time(20, || unsafe { Module::deserialize(&e, &sm).unwrap() }),
        time(20, || unsafe { Component::deserialize(&e, &sc).unwrap() }));
    println!("instantiate (isolated store): core {:?}, component {:?}",
        time(200, || { let mut s = store(&e, 1 << 30, false, false); Linker::<Host>::new(&e).instantiate(&mut s, &cm).unwrap() }),
        time(200, || { let mut s = store(&e, 1 << 30, false, false); Plugin::instantiate(&mut s, &cc, &CLinker::<Host>::new(&e)).unwrap() }));

    println!("\n## infer call latency (median; includes instantiate + encode/decode)");
    println!("{:>6} {:>7} {:>10} | {:>11} {:>11} {:>11} | {:>11}", "roots", "pad", "json B", "core+json", "core+msgp*", "core fuel+ep", "component");
    for (n, pad, reps) in [(1, 0, 200), (100, 0, 100), (1000, 0, 30), (1000, 100, 15), (2000, 400, 5)] {
        let roots = logic::workload(n, pad);
        let json = serde_json::to_vec(&roots)?;
        let wit = to_wit(&roots);
        let expect = logic::infer(&roots).len();
        assert_eq!(core_call(&e, &cm, &json, false, false)?, expect);
        assert_eq!(comp_call(&e, &cc, &wit, false, false)?, expect);
        let t_core = time(reps, || core_call(&e, &cm, &json, false, false).unwrap());
        // msgpack column: host-side encode cost only (guest uses JSON) to show serializer cost
        let t_mp = time(reps, || rmp_serde::to_vec(&roots).unwrap());
        let ef = engine(true, true)?;
        let cmf = Module::new(&ef, &core_bytes)?;
        let t_core_fe = time(reps, || core_call(&ef, &cmf, &json, true, true).unwrap());
        let t_comp = time(reps, || comp_call(&e, &cc, &wit, false, false).unwrap());
        println!("{n:>6} {pad:>7} {:>10} | {t_core:>11.2?} {t_mp:>11.2?} {t_core_fe:>11.2?} | {t_comp:>11.2?}", json.len());
    }
    println!("(* msgpack column = host encode only; guest decoder not built)");
    println!("\n## component with fuel+epoch");
    let ef = engine(true, true)?;
    let ccf = Component::new(&ef, &comp_bytes)?;
    let roots = logic::workload(1000, 0);
    let wit = to_wit(&roots);
    println!("1000 roots: {:?}", time(30, || comp_call(&ef, &ccf, &wit, true, true).unwrap()));

    println!("\n## enforcement");
    let ef = engine(true, true)?;
    let cmf = Module::new(&ef, &core_bytes)?;
    let ccf = Component::new(&ef, &comp_bytes)?;

    // fuel
    let mut s = store(&ef, 1 << 30, true, true); s.set_fuel(5_000_000)?;
    let i = Linker::<Host>::new(&ef).instantiate(&mut s, &cmf)?;
    let t = Instant::now();
    let r = i.get_typed_func::<(), ()>(&mut s, "spin")?.call(&mut s, ());
    println!("core spin, fuel 5M: {} after {:?}", r.err().map(|e| e.root_cause().to_string()).unwrap_or("completed".into()), t.elapsed());
    let mut s = store(&ef, 1 << 30, true, true); s.set_fuel(5_000_000)?;
    let p = Plugin::instantiate(&mut s, &ccf, &CLinker::<Host>::new(&ef))?;
    let t = Instant::now();
    let r = p.omni_proto_discovery().call_spin(&mut s);
    println!("component spin, fuel 5M: {} after {:?}", r.err().map(|e| e.root_cause().to_string()).unwrap_or("completed".into()), t.elapsed());

    // epoch (wall-clock deadline, fuel unlimited)
    for kind in ["core", "component"] {
        let mut s = store(&ef, 1 << 30, true, true);
        s.set_epoch_deadline(1);
        let eng = ef.clone();
        let h = std::thread::spawn(move || { std::thread::sleep(Duration::from_millis(50)); eng.increment_epoch(); });
        let t = Instant::now();
        let r = if kind == "core" {
            let i = Linker::<Host>::new(&ef).instantiate(&mut s, &cmf)?;
            i.get_typed_func::<(), ()>(&mut s, "spin")?.call(&mut s, ()).map_err(|e| e.root_cause().to_string())
        } else {
            let p = Plugin::instantiate(&mut s, &ccf, &CLinker::<Host>::new(&ef))?;
            p.omni_proto_discovery().call_spin(&mut s).map_err(|e| e.root_cause().to_string())
        };
        h.join().unwrap();
        println!("{kind} spin, epoch 50ms: {:?} after {:?}", r, t.elapsed());
    }

    // memory limit: 64 MiB cap, guest asks for 256 MiB
    for kind in ["core", "component"] {
        let mut s = store(&ef, 64 << 20, true, true);
        let r = if kind == "core" {
            let i = Linker::<Host>::new(&ef).instantiate(&mut s, &cmf)?;
            i.get_typed_func::<u32, u32>(&mut s, "grow")?.call(&mut s, 4096).map_err(|e| e.root_cause().to_string())
        } else {
            let p = Plugin::instantiate(&mut s, &ccf, &CLinker::<Host>::new(&ef))?;
            p.omni_proto_discovery().call_grow(&mut s, 4096).map_err(|e| e.root_cause().to_string())
        };
        println!("{kind} grow 256MiB, cap 64MiB: {:?}", r);
    }

    // trap containment, then host continues with a fresh store
    for kind in ["core", "component"] {
        let mut s = store(&ef, 1 << 30, true, true);
        let r = if kind == "core" {
            let i = Linker::<Host>::new(&ef).instantiate(&mut s, &cmf)?;
            i.get_typed_func::<(), ()>(&mut s, "trap")?.call(&mut s, ()).map_err(|e| e.root_cause().to_string())
        } else {
            let p = Plugin::instantiate(&mut s, &ccf, &CLinker::<Host>::new(&ef))?;
            p.omni_proto_discovery().call_trap(&mut s).map_err(|e| e.root_cause().to_string())
        };
        println!("{kind} trap: {:?}", r);
    }
    let roots = logic::workload(3, 0);
    println!("host still healthy after traps: core={} component={}",
        core_call(&ef, &cmf, &serde_json::to_vec(&roots)?, true, true)?,
        comp_call(&ef, &ccf, &to_wit(&roots), true, true)?);

    // ambient authority: imports present
    println!("\n## imports");
    println!("core imports: {:?}", cm.imports().map(|i| format!("{}::{}", i.module(), i.name())).collect::<Vec<_>>());
    println!("component imports: {:?}", cc.component_type().imports(&e).map(|(n, _)| n.to_string()).collect::<Vec<_>>());
    Ok(())
}
```

```rust
fn engine() -> Result<Engine> {

    Engine::new(&c)

fn store(e: &Engine) -> Store<H> {
    let mut s = Store::new(e, H);
    s.set_epoch_deadline(1);
    s
}

fn tick(e: &Engine, after: Duration) -> std::thread::JoinHandle<()> {
    let e = e.clone();
    std::thread::spawn(move || { std::thread::sleep(after); e.increment_epoch(); })
}

#[tokio::main(flavor = "current_thread")]
async fn main() -> Result<()> {
    let a: Vec<String> = std::env::args().collect();
    let e = engine()?;
    let comp = Component::from_file(&e, &a[1])?;
    let acomp = Component::from_file(&e, &a[2])?;
    let ms = 1000u32;

    println!("## blocked host call ({ms} ms), epoch deadline 50 ms, deadline timeout 50 ms");

    // 1. sync host import, sync call: a thread-blocking host function ignores epochs.
    let mut s = store(&e);
    let mut l = Linker::<H>::new(&e);
    syncw::Plugin::add_to_linker::<_, wasmtime::component::HasSelf<_>>(&mut l, |h| h)?;
    let p = syncw::Plugin::instantiate(&mut s, &comp, &l)?;
    let h = tick(&e, Duration::from_millis(50));
    let t = Instant::now();
    let r = p.omni_proto_discovery().call_call_block(&mut s, ms);
    h.join().unwrap();
    println!("sync import, sync call:       {:?} after {:?}", r.map_err(|e| e.root_cause().to_string()), t.elapsed());

    // 2. host-async import, cancelled by dropping the future after a timeout.
    let mut s = store(&e);
    let mut l = Linker::<H>::new(&e);
    asyncw::Plugin::add_to_linker::<_, wasmtime::component::HasSelf<_>>(&mut l, |h| h)?;
    let p = asyncw::Plugin::instantiate_async(&mut s, &comp, &l).await?;
    let t = Instant::now();
    let r = tokio::time::timeout(Duration::from_millis(50), p.omni_proto_discovery().call_call_block(&mut s, ms)).await;
    println!("async host import, timeout:   {} after {:?}", if r.is_err() { "cancelled".to_string() } else { "completed".into() }, t.elapsed());

    // 3. Component Model `async func` guest + async host import, same timeout.
    let mut s = store(&e);
    let mut l = Linker::<H>::new(&e);
    cmw::PluginAsync::add_to_linker::<_, wasmtime::component::HasSelf<_>>(&mut l, |h| h)?;
    let p = cmw::PluginAsync::instantiate_async(&mut s, &acomp, &l).await?;
    let t = Instant::now();
    let r = tokio::time::timeout(Duration::from_millis(50), s.run_concurrent(async |a| p.omni_proto_discovery_async().call_call_block(a, ms).await)).await;
    println!("CM async func, timeout:       {} after {:?}", if r.is_err() { "cancelled".to_string() } else { "completed".into() }, t.elapsed());

    println!("\n## concurrency: 8 calls x 200 ms blocking host service, one thread");
    let n = 8;
    let t = Instant::now();
    for _ in 0..n {
        let mut s = store(&e);
        e.increment_epoch(); // keep deadlines irrelevant

        let p = syncw::Plugin::instantiate(&mut s, &comp, &l)?;
        p.omni_proto_discovery().call_call_block(&mut s, 200)?;
    }
    println!("sync, sequential:             {:?}", t.elapsed());
    let t = Instant::now();
    let mut futs = Vec::new();
    for _ in 0..n {
        let e = e.clone();
        let comp = comp.clone();
        futs.push(async move {
            let mut s = Store::new(&e, H);
            s.set_epoch_deadline(u64::MAX / 2);
            let mut l = Linker::<H>::new(&e);
            asyncw::Plugin::add_to_linker::<_, wasmtime::component::HasSelf<_>>(&mut l, |h| h).unwrap();
            let p = asyncw::Plugin::instantiate_async(&mut s, &comp, &l).await.unwrap();
            p.omni_proto_discovery().call_call_block(&mut s, 200).await.unwrap()
        });
    }
    futures_util_join(futs).await;
    println!("async host import, concurrent: {:?}", t.elapsed());

    println!("\n## async-path overhead (instantiate + call, median of 50)");

    let mut v = Vec::new();

async fn futures_util_join<F: std::future::Future + 'static>(futs: Vec<F>) {
    let mut set = tokio::task::JoinSet::new();
    let local = tokio::task::LocalSet::new();
    local.run_until(async {
        for f in futs { set.spawn_local(async move { f.await; }); }
        while set.join_next().await.is_some() {}
    }).await;
}
```

```rust
use std::time::{Duration, Instant};
use wasmtime::component::{Component, Linker};
use wasmtime::{Config, Engine, InstanceAllocationStrategy, PoolingAllocationConfig, Result, Store};

mod w {
    wasmtime::component::bindgen!({
        world: "plugin", path: "../omni_wasm_proto_guest_component/wit",
        imports: { default: async }, exports: { default: async },
    });

struct H;
impl w::omni::proto::host::Host for H {

fn eng(pool: bool) -> Result<Engine> {
    let mut c = Config::new();
    c.epoch_interruption(true);
    if pool {
        let mut p = PoolingAllocationConfig::new();
        p.total_component_instances(64).total_memories(64).total_stacks(64).total_tables(64);
        c.allocation_strategy(InstanceAllocationStrategy::Pooling(p));
    }
    Engine::new(&c)
}

fn med(mut v: Vec<Duration>) -> Duration { v.sort(); v[v.len() / 2] }

#[tokio::main(flavor = "current_thread")]
async fn main() -> Result<()> {
    let path = std::env::args().nth(1).unwrap();
    for pool in [false, true] {
        let e = eng(pool)?;
        let comp = Component::from_file(&e, &path)?;
        let mut l = Linker::<H>::new(&e);
        w::Plugin::add_to_linker::<_, wasmtime::component::HasSelf<_>>(&mut l, |h| h)?;
        let pre = l.instantiate_pre(&comp)?;
        let (mut t_store, mut t_inst, mut t_call, mut t_sync) = (vec![], vec![], vec![], vec![]);
        for i in 0..300 {
            let t = Instant::now();
            let mut s = Store::new(&e, H);
            s.set_epoch_deadline(u64::MAX / 2);
            let a = t.elapsed();
            let t = Instant::now();
            let inst = pre.instantiate_async(&mut s).await?;
            let p = w::Plugin::new(&mut s, &inst)?;
            let b = t.elapsed();
            let t = Instant::now();
            p.omni_proto_discovery().call_call_block(&mut s, 0).await?;
            let c = t.elapsed();
            if i >= 50 { t_store.push(a); t_inst.push(b); t_call.push(c); }
            // sync-instantiate comparison on the same engine
            let t = Instant::now();
            let mut s = Store::new(&e, H);
            s.set_epoch_deadline(u64::MAX / 2);
            let inst = pre.instantiate_async(&mut s).await?;
            drop(inst);
            if i >= 50 { t_sync.push(t.elapsed()); }
        }
        println!("pooling={pool}: store {:?}, instantiate_pre+instantiate_async {:?}, call {:?}, total-instantiate-only {:?}",
            med(t_store), med(t_inst), med(t_call), med(t_sync));
    }
    Ok(())
}
```

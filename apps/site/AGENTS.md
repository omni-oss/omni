# Agent instructions for the site

## Reference docs are generated

`content/docs/references/**` is autogenerated. Do not edit it by hand — the next
run overwrites your change.

- `gen:declspec` runs `omni declspec dump` into `omni-declspec.json`.
- `gen:refdocs` runs `scripts/generate-references` over that spec to write
  `content/docs/references/**`.
- The `gen` task runs both; `build` depends on `gen:refdocs`.

## Source code is the source of truth

What the reference pages say comes from the CLI definition in Rust:
`crates/omni_cli_core/src/commands/**` (clap `#[command(...)]` attributes, doc
comments, argument help and value descriptions), surfaced through
`crates/clap_declspec`. Generated pages are a projection of that code.

So when a reference page needs to change, change the source, not the page:

- Fix wording, usage, options, defaults or value lists in the relevant command
  definition under `crates/omni_cli_core/src/commands/`.
- If the generator or its templates are wrong or missing a field, change
  `scripts/generate-references/**`.
- Regenerate with `omni run gen:refdocs -p @omni-oss/site` (or
  `omni run gen -p @omni-oss/site`) and include the regenerated output in the
  same change.

Do not add content directly to `content/docs/references/**`. Hand-written
tutorials, guides and explanations belong under `content/docs/guides` (or the
other non-reference directories) instead.

## Other generated files

- `solid-env.d.ts` is generated from `env.ts` — edit the schema, not the file.
- `src/routeTree.gen.ts` is generated by TanStack Router from `src/routes` —
  edit routes, not the tree.

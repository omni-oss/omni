---

title: "pack"

description: "Inspect source packs declared in the workspace"

---



## Usage

```bash
omni pack <SUBCOMMAND>
```

---

## Subcommands

- [`list`](pack/list) - List the top-level packs declared in the workspace

- [`tree`](pack/tree) - Print the expanded pack-of-packs graph

- [`info`](pack/info) - Show one pack and its subtree by qualified id

---

## Examples

```bash
omni pack <SUBCOMMAND>
```

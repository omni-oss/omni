---

title: "explain"

description: "Explain an error or notice code"

---



## Usage

```bash
omni explain [OPTIONS] <code>
```

---

## Positional arguments

### `<code>`

The code to explain, for example `meta.filter_failed`

- **Required:** Yes

---

## Options

### `-f`, `--format`

The format to use for the output

- **Required:** No

- **Default:** `text`

- **Possible values:** `text`, `json`

---

## Examples

```bash
omni explain [OPTIONS] <code>
```

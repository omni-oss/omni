## Usage

```bash
omni cache <SUBCOMMAND>
```

---

## Subcommands

- [`dir`](cache/dir) - Print the cache directory

- [`stats`](cache/stats) - Show statistics about the cache

- [`eligibility`](cache/eligibility) - Show each selected task's cache eligibility and explicit cache.enabled contradictions, without running anything

- [`prune`](cache/prune) - Prune the local cache

- [`keygen`](cache/keygen) - Generate an Ed25519 key pair for signing shared remote cache entries

- [`remote`](cache/remote) - Remote cache related commands

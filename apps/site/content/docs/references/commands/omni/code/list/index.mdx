---

title: "list"

description: "List every error and notice code"

---



## Usage

```bash
omni code list [OPTIONS]
```

---

## Options

### `-f`, `--format`

The format to use for the output

- **Required:** No

- **Default:** `text`

- **Possible values:** `text`, `json`, `md`

### `-k`, `--kind`

Only list codes of this kind

- **Required:** No

- **Possible values:** `error`, `notice`

---

## Examples

```bash
omni code list [OPTIONS]
```

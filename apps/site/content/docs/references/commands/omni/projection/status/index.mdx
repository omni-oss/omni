---

title: "status"

description: "Report the state of recorded projection links"

---



## Usage

```bash
omni projection status [OPTIONS]
```

---

## Options

### `-v`, `--verbose`

List every recorded link, not just a summary

- **Required:** No

- **Default:** `false`

- **Possible values:** `true`, `false`

---

## Examples

```bash
omni projection status [OPTIONS]
```

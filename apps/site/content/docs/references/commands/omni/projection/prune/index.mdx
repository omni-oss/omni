---

title: "prune"

description: "Remove links whose destinations have become dangling"

---



## Usage

```bash
omni projection prune [OPTIONS]
```

---

## Options

### `--dry-run`

Report what would be pruned without removing anything

- **Required:** No

- **Default:** `false`

- **Possible values:** `true`, `false`

---

## Examples

```bash
omni projection prune [OPTIONS]
```

---

title: "inspect"

description: "Show a tool's input schema"

---



## Usage

```bash
omni tool inspect [OPTIONS] <name>
```

---

## Positional arguments

### `<name>`

Name of the tool to inspect

- **Required:** Yes

---

## Options

### `--pretty`

Pretty-print the JSON output

- **Required:** No

- **Default:** `false`

- **Possible values:** `true`, `false`

---

## Examples

```bash
omni tool inspect [OPTIONS] <name>
```

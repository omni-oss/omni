## Usage

```bash
omni diagnostics list [OPTIONS]
```

---

## Options

### `-f`, `--format`

The format to use for the output

- **Required:** No

- **Default:** `text`

- **Possible values:** `text`, `json`, `md`

---

## Examples

```bash
omni diagnostics list [OPTIONS]
```

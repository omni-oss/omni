---
title: "prune"

description: "Delete checkouts from the remote-source store by age or size. They are refetched when next used"
---

## Usage

```bash
omni remote-sources prune [OPTIONS]
```

At least one of `--older-than`, `--larger-than` or `--all` is required. When
several filters are given a checkout must match all of them. See the
[remote-source store](/docs/references/remote-source-store).

---

## Options

### `-o`, `--older-than`

Only checkouts last used longer ago than this (for example `30d`)

- **Required:** No

### `-l`, `--larger-than`

Only checkouts larger than this (for example `100MB`)

- **Required:** No

### `--all`

Select every checkout in the store

- **Required:** No

- **Default:** `false`

- **Possible values:** `true`, `false`

### `-y`, `--yes`

Prune without prompting for confirmation

- **Required:** No

- **Default:** `false`

- **Possible values:** `true`, `false`

### `-d`, `--dry-run`

Show the checkouts that would be deleted

- **Required:** No

- **Default:** `false`

- **Possible values:** `true`, `false`

---

## Examples

```bash
omni remote-sources prune --older-than 30d --dry-run
omni remote-sources prune --all --yes
```

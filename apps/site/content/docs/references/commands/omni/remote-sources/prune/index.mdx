title: "prune"

description: "Delete checkouts from the remote-source store. They are refetched when next used"

---



Delete checkouts from the remote-source store. They are refetched when next used.

Checkouts leased by a running command, or referenced by a registered workspace, are skipped and reported. Workspaces register when they write references (install, or a generator or tool run). An older omni version prunes without reading registrations, so it can delete a checkout a newer workspace still references.

## Usage

```bash
omni remote-sources prune [OPTIONS]
```

---

## Options

### `--unused`

Select checkouts that no running command holds and no registered workspace references. Workspaces register when they write references (install, or a generator or tool run).

- **Required:** No

- **Possible values:** `true`, `false`

### `-o`, `--older-than`

Only checkouts last used longer ago than this (for example 30d)

- **Required:** No

### `-l`, `--larger-than`

Only checkouts larger than this (for example 100MB)

- **Required:** No

### `--all`

Select every checkout in the store (not combinable with --older-than or --larger-than)

- **Required:** No

- **Possible values:** `true`, `false`

### `-y`, `--yes`

Prune without prompting for confirmation

- **Required:** No

- **Possible values:** `true`, `false`

### `-d`, `--dry-run`

Show the checkouts that would be deleted

- **Required:** No

- **Possible values:** `true`, `false`

---

## Examples

```bash
omni remote-sources prune [OPTIONS]
```

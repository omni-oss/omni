## Usage

```bash
omni project list [OPTIONS]
```

---

## Options

### `-r`, `--raw`

Only print the raw list, no logs will be added

- **Required:** No

- **Possible values:** `true`, `false`

### `-f`, `--format`

If provided, the list will be serialized in the format specified

- **Required:** No

- **Possible values:** `json`, `yaml`, `toml`

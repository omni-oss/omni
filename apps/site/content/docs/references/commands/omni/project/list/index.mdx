title: "list"

---



## Usage

```bash
omni project list [OPTIONS]
```

---

## Options

### `-r`, `--raw`

Only print the raw list, no logs will be added

- **Required:** No

- **Possible values:** `true`, `false`

### `-f`, `--format`

If provided, the list will be serialized in the format specified

- **Required:** No

- **Possible values:** `json`, `yaml`, `toml`

### `--include-base`

Also list base templates (configs with `base: true`)

- **Required:** No

- **Possible values:** `true`, `false`

### `--include-extended`

Also list configs that are only reached through `extends`

- **Required:** No

- **Possible values:** `true`, `false`

### `--all`

List every loaded project configuration

- **Required:** No

- **Possible values:** `true`, `false`

---

## Examples

```bash
omni project list [OPTIONS]
```

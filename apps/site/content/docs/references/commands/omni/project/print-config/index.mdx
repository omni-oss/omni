title: "print-config"

---



## Usage

```bash
omni project print-config [OPTIONS] [project_name]
```

---

## Positional arguments

### `[project_name]`

Name of the project whose configuration to print

- **Required:** No

---

## Options

### `-f`, `--format`

Format to use when serializing

- **Required:** No

- **Default:** `json`

- **Possible values:** `json`, `yaml`, `toml`

### `--path`

Path to the project configuration file to print. Relative paths are resolved against the current directory

- **Required:** No

### `-r`, `--raw`

Only print the raw configuration syntax, no logs will be added

- **Required:** No

- **Possible values:** `true`, `false`

---

## Examples

```bash
omni project print-config [OPTIONS] [project_name]
```

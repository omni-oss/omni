---

title: "projection"

description: "Materialize files from sources into the workspace via links"

---



## Usage

```bash
omni projection <SUBCOMMAND>
```

---

## Subcommands

- [`sync`](projection/sync) - Materialize configured projections into the workspace

- [`status`](projection/status) - Report the state of recorded projection links

- [`unlink`](projection/unlink) - Remove the links recorded for a projection source

- [`prune`](projection/prune) - Remove links whose destinations have become dangling

---

## Examples

```bash
omni projection <SUBCOMMAND>
```

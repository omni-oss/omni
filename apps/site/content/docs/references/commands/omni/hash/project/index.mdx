---

title: "project"

description: "Get the hash for a project"

---



## Usage

```bash
omni hash project [OPTIONS] <project>
```

---

## Positional arguments

### `<project>`

Project name

- **Required:** Yes

---

## Options

### `-t`, `--task`

Hash only the task with this exact name (a task or an alias; `project#task` must name this project). Glob characters are literal; use --task-pattern to match by glob

- **Required:** No

### `--task-pattern`

Hash only the tasks whose name matches this glob. Repeatable, and may be combined with --task

- **Required:** No

---

## Examples

```bash
omni hash project [OPTIONS] <project>
```

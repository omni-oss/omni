---

title: "ignore"

description: "Maintain omni's managed block in ignore files (.gitignore, .ignore, .omniignore)"

---



## Usage

```bash
omni ignore <SUBCOMMAND>
```

---

## Subcommands

- [`sync`](ignore/sync) - Patch omni's managed block into every configured ignore file

- [`clean`](ignore/clean) - Remove omni's managed block from every configured ignore file

---

## Examples

```bash
omni ignore <SUBCOMMAND>
```

## Aliases

`remote-source`

## Usage

```bash
omni remote-sources <SUBCOMMAND>
```

---

## Subcommands

- [`install`](remote-sources/install) - Prefetch and pin every remote source declared in the workspace
- [`prune`](remote-sources/prune) - Delete checkouts from the remote-source store by age or size. They are refetched when next used

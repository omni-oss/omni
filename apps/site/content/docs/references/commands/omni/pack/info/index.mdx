---

title: "info"

description: "Show one pack and its subtree by qualified id"

---



## Usage

```bash
omni pack info <qualified_id>
```

---

## Positional arguments

### `<qualified_id>`

The qualified id of the pack (or subtree) to inspect

- **Required:** Yes

---

## Examples

```bash
omni pack info <qualified_id>
```

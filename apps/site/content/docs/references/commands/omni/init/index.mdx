---

title: "init"

description: "Initialize a new workspace in the current directory"

---



## Usage

```bash
omni init [OPTIONS]
```

---

## Options

### `-g`, `--git`

The git repository URL to clone for initializing the workspace

- **Required:** No

### `--git-rev`

The git revision to use when cloning the repository (e.g., branch, tag, or commit hash

- **Required:** No

### `-o`, `--output`

The output directory for the initialized workspace

- **Required:** No

### `-v`, `--value`

Prefill values to inputs

- **Required:** No

### `--use-defaults`

Use default values for inputs

- **Required:** No

- **Default:** `false`

- **Possible values:** `true`, `false`

---

## Examples

```bash
omni init [OPTIONS]
```

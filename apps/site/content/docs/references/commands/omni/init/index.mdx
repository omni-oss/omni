---

title: "init"

description: "Initialize a new workspace in the current directory"

---



## Usage

```bash
omni init [OPTIONS]
```

---

## Options

### `-g`, `--git`

The git repository URL to clone for initializing the workspace

- **Required:** No

### `--git-rev`

The git revision to use when cloning the repository (e.g., branch, tag, or commit hash

- **Required:** No

### `-o`, `--output`

The output directory for the initialized workspace

- **Required:** No

### `-v`, `--value`

Prefill values to inputs. Values are passed as plain strings (unlike `omni tool run --value`, which parses JSON when possible)

- **Required:** No

### `--use-defaults`

Use default values for inputs

- **Required:** No

- **Default:** `false`

- **Possible values:** `true`, `false`

### `--redact-input`

Redact the value of this input (name or glob) in logs. Repeatable

- **Required:** No

### `--redact-env`

Redact the value of this environment variable (name or glob) in logs. Repeatable

- **Required:** No

### `--redact`

Redaction mode: declared (apply configured policy), all, or none (prints a notice)

- **Required:** No

- **Possible values:** `declared`, `all`, `none`

---

## Examples

```bash
omni init [OPTIONS]
```
